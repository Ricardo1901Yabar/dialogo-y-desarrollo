# Revista Digital - Diálogo y Desarrollo

Plataforma web dinámica para la gestión y publicación de contenidos editoriales, reportajes, boletines y podcasts, desarrollada en PHP y MySQL con panel de administración modular.

## Características
- **Portal Público:** Visualización de publicaciones, diseño responsive y navegación por categorías.
- **Panel Administrativo (`revista_admin`):**
  - Gestión de usuarios y control de accesos basado en roles (Admin, Editor, Redactor).
  - Módulo CRUD para reportajes, noticias y boletines.
  - Gestión de autores y contenido multimedia.
  - Conexión a base de datos mediante PDO.

## Tecnologías
- **Backend:** PHP
- **Base de Datos:** MySQL / MariaDB (vía PDO)
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5, FontAwesome
- **Despliegue:** InfinityFree Hosting
